abstract: "Models trained only in simulation can be used to solve a manipulation problem of unprecedented complexity on a real robot. This achievement relies on a novel algorithm, which we call automatic domain randomization (ADR), that continuously expands the distribution of simulated environments as the agent becomes more capable. The key insight is that instead of manually specifying the range of domain randomization parameters, ADR automatically widens them when the agent masters the current distribution, progressively increasing task difficulty."
